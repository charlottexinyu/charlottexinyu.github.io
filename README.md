# Research website
[AI for Business](https://charlottexinyu.github.io/ai-for-business/) provides research statistics, discipline directories and source-linked summaries of AI research in business and economics.

The website is published from the main branch. AI for Business updates are maintained in the owner's monthly Codex automation. The current paper data and reproducible build instructions are in [source/ai-for-business](source/ai-for-business/README.md).
